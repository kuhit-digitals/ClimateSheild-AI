        Transparent Deterministic Risk Formula

        This application uses a deterministic rule-based calculation to ensure 100% auditable, repeatable risk scores without black-box machine learning hallucination.

        overall_score = round( 0.40 × financial_vulnerability + 0.60 × average(flood, heat, water) )

        Risk Classification Bands

        • Low : 0 to 29 (Standard monitoring)
        • Moderate : 30 to 49 (Periodic review)
        • Elevated : 50 to 69 (Mitigation advisory suggested)
        • High : 70 to 100 (Immediate underwriting review)

        Supabase Integration

        The backend uses the existing businesses and simulations tables through the API. Scores and climate averages are calculated in JavaScript; no schema migration is required.

        Configure SUPABASE_URL and the server-only SUPABASE_SERVICE_ROLE_KEY in the local .env file. Keep Row Level Security enabled.
